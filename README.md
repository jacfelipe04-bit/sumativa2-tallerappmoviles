---------------------------------------------------------------------------------
----------------------- INSTALACIÓN DESDE GITHUB -------------------------------
---------------------------------------------------------------------------------

1. Ingrese al repositorio del proyecto:

   https://github.com/jacfelipe04-bit/sumativa2-tallerappmoviles

2. Presione el botón "Code".

3. Seleccione la opción "Download ZIP".

4. Extraiga el contenido descargado en una carpeta de su preferencia.

5. Abra Android Studio.

6. Seleccione "Open" y elija la carpeta del proyecto extraída.

7. Espere a que Android Studio sincronice las dependencias del proyecto.

8. Presione el botón "Run" para compilar y ejecutar la aplicación.

---------------------------------------------------------------------------------
---------------------- INSTALACIÓN DESDE ARCHIVO .ZIP --------------------------
---------------------------------------------------------------------------------

1. Ingrese al portafolio del proyecto:

   https://drive.google.com/drive/folders/1-WtDXH7NnP1qUyMT4kRIFhrtZd7SSFcx

2. Descargue el archivo "CarnetSanitario.zip".

3. Extraiga el contenido del archivo ZIP.

4. Abra Android Studio.

5. Seleccione "Open" y abra la carpeta del proyecto extraído.

6. Espere a que Android Studio complete la sincronización del proyecto.

7. Ejecute la aplicación utilizando el botón "Run".

---------------------------------------------------------------------------------
------------------------- INSTALACIÓN DESDE APK -------------------------------
---------------------------------------------------------------------------------

1. Ingrese al portafolio del proyecto:

   https://drive.google.com/drive/folders/1-WtDXH7NnP1qUyMT4kRIFhrtZd7SSFcx

2. Descargue el archivo "app-debug.apk".

3. Transfiera el archivo a un dispositivo Android si fue descargado desde un computador.

4. Abra el archivo APK desde el dispositivo Android.

5. Si es necesario, habilite la opción para instalar aplicaciones de origen desconocido.

6. Complete la instalación siguiendo las instrucciones del dispositivo.

7. Una vez instalada, abra la aplicación desde el menú de aplicaciones.
